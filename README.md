# LibreGo (自由影梭)

> **LibreGo** 是一款基於 Android 系統 API 構建的純粹、現代、完全自由的虛擬定位（Mock Location）與路線模擬工具。
> 
> 本專案基於原開源專案 `GoGoGo (影梭)` 進行維護與重構，致力於回歸自由開源軟體（FOSS）的初衷，**堅守 GPL-3.0 協議**。**無帳號體系、無聯網驗證、無會員付費、無卡密廣告，所有功能 100% 離線可用且永遠免費開源。**

---

## 🌟 核心特色 (v2.0+)

### 1. 現代 Android 系統與防跳點深度優化
* **三 Provider 同步偽裝**：同步向系統註冊 `gps`、`network` 以及 **`fused`（融合定位）** 測試提供者，徹底解決現代 App（打卡、社交、遊戲等）在真實位置與模擬位置之間來回「跳點」的頑疾。
* **嚴格單調時間戳**：採用高精度單調奈秒計時，杜絕因系統時間抖動而被 Android 定位快取判定為過期資料拋棄的問題。
* **物理特徵訊號模擬**：
  * 動態 GPS 精度抖動（依移動速度動態計算精度並加入微幅隨機雜訊，避免死板固定數值）。
  * 支援垂直精度、航向角精度、速度精度（Android 8.0+ API 規範）。
  * 模擬隨機衛星可見顆數（有效應對讀取衛星狀態的檢測機制）。
* **全面適配 Android 13 / 14 / 15**：完善 Foreground Service 宣告與動態通知權限，保證後台服務穩定不被系統強殺。

### 2. 靈活的移動控制與路線規劃
* **全功能懸浮搖桿**：支援圓形搖桿與方向按鈕，支援自定義大小與透明度，隨時切換步行、跑步、騎行等運動速度。
* **多點路線模擬**：在地圖上自定義折線路徑，支援按設定速度沿途巡航移動，支援單次與循環播放。
* **GPX 支援**：支援匯入與匯出標準 GPX 軌跡文件。
* **精準座標與搜尋**：支援 WGS-84、GCJ-02、BD-09 座標輸入與地點搜尋。

### 3. 純粹與安全
* 🔒 **零隱私上傳**：所有位置、歷史與收藏資料均儲存於本機 SQLite，不連線任何私有伺服器。
* 🚫 **無任何收費牆**：不設會員、無授權碼、無分身付費限制，源碼透明。

## 🚀 快速上手

1. **安裝應用**：在 [Releases](https://github.com/...) 下載最新的 `LibreGo-v2.x.apk` 並安裝。
2. **開啟模擬位置權限**：
   * 開啟手機的 **「系統設定」->「開發者選項」**。
   * 找到 **「選取模擬位置資訊應用程式」**（Mock Location App），選擇 **LibreGo**。
3. **授予定位與懸浮窗權限**：
   * 首次啟動依提示授予基礎定位權限。
   * 若需使用懸浮搖桿，請允許「顯示在其他應用程式上層」（懸浮窗權限）。
4. **開始穿梭**：在地圖上選取目標點或搜尋地點，點擊啟動即可！

## 🛠️ 開發與編譯

本專案使用標準 Android Gradle 構建系統：

```bash
# 複製倉庫
git clone https://github.com/YourUsername/LibreGo.git
cd LibreGo

# 編譯 Debug APK
./gradlew assembleDebug

# 編譯 Release APK
./gradlew assembleRelease
```
